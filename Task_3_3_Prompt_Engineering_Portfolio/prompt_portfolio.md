## 4. Coding

### Goal
To compare a basic coding prompt with a more specific prompt that includes type hints, documentation, error handling, and test cases.

### Baseline Prompt
Write Python code for this task:

Write a Python function called calculate_average that takes a list of numbers and returns their average.

### Baseline Output
def calculate_average(numbers):
    return sum(numbers) / len(numbers)

Example:
numbers = [10, 20, 30, 40]
print(calculate_average(numbers))

Output:
25.0

### Improved Prompt
Write a Python function called calculate_average.

Requirements:
1. The function must accept a list of numbers.
2. Return the arithmetic mean.
3. If the list is empty, raise a ValueError with a clear error message.
4. Include a Python type hint.
5. Include a short docstring.
6. Keep the implementation simple and readable.
7. Provide two example test cases.

### Improved Output
def calculate_average(numbers: list[float]) -> float:
    """Return the arithmetic mean of a list of numbers."""
    if not numbers:
        raise ValueError("The list of numbers cannot be empty.")
    return sum(numbers) / len(numbers)

# Test case 1
print(calculate_average([10, 20, 30, 40]))  # 25.0

# Test case 2
print(calculate_average([5, 10, 15]))  # 10.0

### Evaluation
Scores from 1 to 5:

**Baseline**
- Correctness: 5/5 for a non-empty list.
- Completeness: 4/5 because the prompt does not specify empty-list handling, type hints, documentation, or test cases.
- Format Adherence: 5/5
- Clarity: 5/5

**Improved**
- Correctness: 5/5 for the requested normal inputs and empty-list handling.
- Completeness: 5/5
- Format Adherence: 5/5
- Clarity: 5/5

### What Changed
The improved prompt specified empty-list error handling, a return type hint, a docstring, a simple implementation, and two example test cases.

### Outcome
The improved prompt produced a more complete function. It handles empty input with a ValueError and includes documentation and test examples. The generated code should still be tested before use.
