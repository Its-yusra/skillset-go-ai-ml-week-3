# Task 3.3 - Prompt Engineering Portfolio

## Objective

This task demonstrates prompt design, testing, iteration, and evaluation across four use cases.

## Use Cases

1. Reasoning
2. Information Extraction
3. Summarization
4. Coding

## Prompt Iteration

Each use case contains:
- Baseline prompt
- Fixed test input
- Baseline output
- Improved prompt
- Improved output
- Evaluation criteria
- Iteration notes

## Evaluation Criteria

- Correctness
- Completeness
- Clarity
- Format adherence
- Code validity where applicable
